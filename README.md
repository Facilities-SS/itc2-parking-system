# ที่จอดรถ — ระบบลงข้อมูลที่จอดรถของแผนก ITC2

ลิงก์ใช้งาน: **https://paphatsara-srw.github.io/itc2-parking-system/**
เปิดได้จากอินเทอร์เน็ต แต่คนนอกจะเห็นแค่หน้าล็อกอิน เข้าได้เฉพาะชื่อผู้ใช้ที่ผู้ดูแลสร้างให้

## หน้าในแอป

| หน้า | ใช้ทำอะไร |
| --- | --- |
| **แผนผัง** | ผังโรงงานแตะเลือกลานจอด ผัง 3 มิติของแต่ละลาน ดูว่ารถใครจอดตรงไหน แตะช่องว่างเพื่อจอง ค้นหารถจากทะเบียนหรือชื่อ |
| **วันนี้** | รถที่ขอเข้าจอดแต่ละวัน กรองตามสถานที่ได้ มีสรุปจำนวนรถและรายการทะเบียนไว้แคปส่ง รปภ. และปุ่มคัดลอกข้อความไปวางใน LINE |
| **ตรวจเช็ค** | แทนแบบฟอร์มตรวจเช็ครถประจำวัน แยก **กะกลางวัน 07:00–19:00** และ **กะกลางคืน 19:00–07:00** (กะกลางคืนนับเป็นวันที่เริ่มกะ) ก่อนเริ่มตรวจใส่ชื่อผู้ตรวจเอง แตะทีละช่องว่ามีรถหรือไม่ ทะเบียนตรงหรือไม่ พิมพ์ใบสรุปได้ A4 แผ่นเดียว มีผลทั้ง 2 กะข้างกัน |
| **สรุป** | **อัตราการมาจอดช่องประจำ** รายคน รายเดือน เป็น % เลือกหลายเดือนได้ ไฮไลต์คนที่ต่ำกว่าเกณฑ์ และดาวน์โหลด Excel แบบเดียวกับไฟล์ข้อมูลที่จอดรายเดือน (ตาราง 1/0 รายวัน วันที่จอด วันทั้งหมด %) / การใช้งานตอนนี้ คำขอรายวัน ผลตรวจเช็ค |
| **ข้อมูล** | ช่องประจำพนักงาน (นำเข้า Excel ได้) ประวัติจองชั่วคราว ประวัติตรวจเช็ค ส่งออก CSV |
| **ตั้งค่า** | บัญชีของฉัน (เปลี่ยนรหัสผ่าน) ผู้ใช้ที่เข้าระบบได้ สถานที่และผัง สำรองข้อมูล ถังขยะ 30 วัน |

ทดลองใช้โดยไม่ต้องล็อกอิน: เปิด `index.html?demo=1` (ข้อมูลสมมติ เก็บในเบราว์เซอร์นั้นเท่านั้น) ดูแบบผู้ตรวจ: `index.html?demo=1&role=guard`

## การล็อกอินและบทบาท

บัญชี รปภ. (เช่น `guard01`) ใช้ร่วมกันได้หลายคน ชื่อผู้ตรวจจริงใส่ตอนเริ่มตรวจแต่ละกะ เครื่องจะจำชื่อไว้จนจบกะ เปลี่ยนคนตรวจกลางกะได้ที่ปุ่ม **เปลี่ยนผู้ตรวจ** ผลตรวจแต่ละช่องเก็บทั้งชื่อผู้ตรวจและบัญชีที่ใช้ (ดูได้ในไฟล์ CSV)

ทุกคนล็อกอินด้วย **ชื่อผู้ใช้ + รหัสผ่าน** ที่ผู้ดูแลสร้างให้ ไม่ต้องมี Gmail
(ภายในระบบ ชื่อผู้ใช้ `guard01` จะถูกเก็บเป็น `guard01@parking.local` ไม่มีการส่งอีเมลจริง)

| ทำอะไรได้ | ผู้ตรวจ (รปภ.) | สมาชิก (คนในแผนก) | ผู้ดูแล |
| --- | :-: | :-: | :-: |
| ดูผัง ค้นหารถ เห็นชื่อและทะเบียน | ✓ | ✓ | ✓ |
| บันทึกผลตรวจเช็คประจำวัน | ✓ | ✓ | ✓ |
| เห็นรหัสพนักงาน แผนก ฝ่าย | | ✓ | ✓ |
| จอง ลงทะเบียน แก้ไข ยกเลิก ลบ นำเข้า ส่งออก ดูสรุป | | ✓ | ✓ |
| แก้สถานที่และผัง เพิ่ม/นำผู้ใช้ออก กู้คืนทั้งระบบ | | | ✓ |

### เพิ่มผู้ใช้ใหม่ (ผู้ดูแล)
1. ในแอป: **ตั้งค่า > ผู้ใช้ที่เข้าระบบได้** ใส่ชื่อผู้ใช้ (เช่น `guard01`) ชื่อที่แสดง (เช่น รปภ. สมศักดิ์ กะกลางวัน) เลือกบทบาท แล้วกด **เพิ่มผู้ใช้**
2. ใน Firebase: **Authentication > Users > Add user**
   - Email: `guard01@parking.local` (ระบบแสดงให้คัดลอกหลังกดเพิ่มผู้ใช้)
   - Password: ตั้งอย่างน้อย 8 ตัว
3. แจ้งผู้ใช้: ชื่อผู้ใช้ `guard01` และรหัสผ่านที่ตั้ง ผู้ใช้เปลี่ยนรหัสเองได้ที่ ตั้งค่า > บัญชีของฉัน

พนักงานที่มีอีเมลบริษัท ใช้อีเมลบริษัทเป็นชื่อผู้ใช้ได้เลย เช่น `somchai@thaiunion.com`

### รปภ. ลาออก / ลืมรหัสผ่าน
- **ลาออก:** ในแอปกด **นำออก** และใน Firebase > Authentication > Users กดเมนู ⋮ ของบัญชีนั้น แล้วเลือก **Disable account** หรือ **Delete account**
- **ลืมรหัสผ่าน:** บัญชีแบบชื่อผู้ใช้ไม่มีอีเมลจริง ระบบส่งลิงก์รีเซ็ตไม่ได้ ให้ลบบัญชีใน Firebase แล้ว **Add user** ใหม่ด้วยชื่อเดิมและรหัสผ่านใหม่ (ไม่ต้องแก้ในแอป ข้อมูลการตรวจเดิมไม่หาย)

## ตั้งค่า Firebase สำหรับการล็อกอินแบบชื่อผู้ใช้ (ทำครั้งเดียว)

ทำตามลำดับนี้ ข้อ 1–4 ทำได้ก่อน ข้อ 6 ต้องทำหลังอัปโหลดไฟล์ใหม่ขึ้น GitHub แล้ว

1. **เปิดล็อกอินด้วยรหัสผ่าน:** Authentication > **Sign-in method** > **Add new provider** > **Email/Password** เปิดสวิตช์แรก (Email/Password) แล้วกด Save (ไม่ต้องเปิด Email link)
2. **ปิดการสมัครเอง:** Authentication > **Settings** > **User actions** เอาติ๊ก **Enable create (sign-up)** และ **Enable deletion** ออก แล้วกด Save คนนอกจะสร้างบัญชีเองไม่ได้
3. **สร้างบัญชีผู้ดูแล:** Authentication > **Users** > **Add user** Email `admin@parking.local` และตั้งรหัสผ่าน
4. **ใส่ผู้ดูแลในรายชื่อ:** Firestore > Data > `config` > `access` กด field `admins` > **Add field** ใน array ใส่ค่า `admin@parking.local` (ชนิด string)
5. **อัปโหลดไฟล์ใหม่ขึ้น GitHub:** `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, โฟลเดอร์ `icons`
6. **ใส่กฎใหม่:** Firestore > **Rules** ลบของเดิม วางเนื้อหาจาก `firestore.rules` แล้วกด **Publish**
7. **ปิดล็อกอินด้วย Google:** Authentication > Sign-in method > Google > ปิดสวิตช์ Enable แล้ว Save
8. เปิดแอป กด `Ctrl + F5` ล็อกอินด้วย `admin` และรหัสผ่านจากข้อ 3 แล้วเพิ่มผู้ใช้คนอื่นตามหัวข้อ "เพิ่มผู้ใช้ใหม่"

หลังข้อ 6 อีเมล Gmail ที่อยู่ใน `admins` เดิมจะใช้ไม่ได้แล้ว (กฎรับเฉพาะการล็อกอินด้วยรหัสผ่าน) ลบออกจากรายชื่อในหน้าตั้งค่าได้

## วิธีคิด % การมาจอด
- **วันที่จอด (1):** วันที่ตรวจพบรถทะเบียนตรงกับที่ลงไว้ ในกะกลางวันหรือกะกลางคืนกะใดกะหนึ่ง
- **0:** วันที่ช่องนั้นถูกตรวจ แต่ไม่พบรถ หรือพบรถทะเบียนไม่ตรง
- **วันทั้งหมด:** วันที่ช่องนั้นถูกตรวจเช็ค วันที่ไม่ได้ตรวจไม่นับ
- ผูกกับคนที่มีสิทธิ์จอดในวันที่ตรวจ ถ้าเปลี่ยนเจ้าของช่องกลางเดือน จะแยกเป็นคนละแถว

## ความปลอดภัย
- ต้องล็อกอินด้วยชื่อผู้ใช้ + รหัสผ่าน และชื่อต้องอยู่ในรายชื่อผู้ใช้ ตรวจซ้ำที่ Firestore Rules
- ปิดการสมัครเอง บัญชีสร้างได้เฉพาะผู้ดูแลใน Firebase Console
- ผู้ตรวจบันทึกได้เฉพาะผลตรวจเช็ค Rules ไม่ยอมให้แก้หรือลบข้อมูลอื่น
- ผู้ตรวจไม่เห็นรหัสพนักงาน แผนก ฝ่าย ในหน้าแอป (ข้อมูลนี้ยังอยู่ในเอกสารเดียวกับชื่อและทะเบียน คนที่มีความรู้เทคนิคยังดึงได้ ถ้าต้องการกันขาด แจ้งเพื่อแยกเก็บ)
- ทุกรายการและทุกผลตรวจบันทึกชื่อผู้ทำและเวลา
- กันสองเครื่องจองช่องเดียวกันพร้อมกันด้วย transaction
- ไฟล์สำรองและ CSV มีข้อมูลส่วนบุคคลของพนักงาน เก็บในที่ปลอดภัย
